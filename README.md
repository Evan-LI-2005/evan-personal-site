# 李梦丞 / Evan 的个人空间

静态个人展示网站，记录兴趣、经历与旅行。

个人内容集中在 content.js，外观在 style.css，互动在 app.js 和 planet3d.js。

## 预览

在此目录运行 python3 -m http.server 8080，再访问 http://localhost:8080。

## 发布

GitHub 仓库 Settings → Pages，选择 Deploy from a branch、main 分支与 /(root)，保存即可。

## 许可

代码采用 MIT 许可；个人照片、姓名、经历和联系方式不在该许可范围内，未经许可不得复用。
